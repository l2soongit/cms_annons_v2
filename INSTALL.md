# Встановлення graj.club на віртуальний хостинг

Без SSH і командного рядка: усе робиться через панель хостингу й браузер.

## Що потрібно від хостингу

- PHP 8.2 або новіший (краще 8.3) з розширеннями: pdo_mysql, mbstring, intl, openssl, fileinfo, gd, curl, zip, xml, bcmath; бажано sockets (моніторинг серверів)
- MySQL 5.7+ або MariaDB 10.3+
- Cron (планувальник) з інтервалом 1 хвилина
- Дозвіл вихідних UDP/TCP-з'єднань — без нього моніторинг покаже всі сервери офлайн. Уточніть у хостера

## Кроки

1. **База.** У панелі хостингу («Бази даних MySQL») створіть порожню базу й користувача з повними правами на неї. Запишіть назву бази, користувача й пароль.
2. **Файли.** Завантажте архів `graj-club-….zip` у файловий менеджер хостингу й розпакуйте.
   - **Краще:** розпакуйте в окрему теку (наприклад `graj`) і в налаштуваннях домену вкажіть кореневу теку (document root) `graj/public`.
   - **Якщо панель цього не дозволяє:** розпакуйте прямо в `public_html`. Файл `.htaccess` у корені архіву спрямує всі запити в `public/` і закриє решту файлів.
3. **SSL.** Увімкніть безкоштовний сертифікат Let's Encrypt для домену в панелі.
4. **Інсталятор.** Відкрийте `https://ваш-домен/install.php` (головна сторінка сама перенаправить туди). Інсталятор:
   - перевірить версію PHP, розширення й права на теки;
   - перевірить доступ до бази;
   - запише `.env`, створить таблиці, ігри, тарифи й переклади;
   - створить адміністратора з вашим email і паролем;
   - після успіху заблокується й видалить себе.
5. **Cron.** Додайте задачу, яку покаже інсталятор, з інтервалом «щохвилини»:
   ```
   * * * * * cd /шлях/до/graj && php artisan schedule:run >> /dev/null 2>&1
   ```
6. **Вхід.** Відкрийте `/admin`, увійдіть і налаштуйте двофакторний вхід.

Ключі оплати (LiqPay, Stripe), капчі, входу через Google/Discord, Telegram і бекапів додаються в `.env` пізніше — що де взяти, описано в [DEPLOY.md](DEPLOY.md). Чекліст запуску — у [RELEASE.md](RELEASE.md).

## Якщо щось пішло не так

- **Помилка на кроці встановлення.** Інсталятор показує, на якому кроці зупинився і чому. Виправте причину й надішліть форму ще раз — виконані кроки повторюються безпечно.
- **Не відкриваються логотипи й скріншоти.** Хостинг заборонив symlink: попросіть підтримку створити посилання `public/storage` → `storage/app/public`.
- **Сторінка 500 після встановлення.** Подивіться `storage/logs/laravel-*.log`.
- **Перевстановити.** Видаліть `storage/installed` і `.env`, поверніть `public/install.php` з архіву.

## Оновлення

Кожен коміт у `main`, що пройшов CI, GitHub Actions збирає в архів і публікує як реліз (вкладка Releases репозиторію). Сайт бере оновлення звідти.

**Автоматично.** Адмінка → «Система» → «Оновлення» → «Автооновлення: Увімкнути». Раз на годину cron перевіряє GitHub і сам ставить новий реліз. Потрібен робочий cron.

**Вручну.** Там же:
- «Перевірити» — дізнатися, чи є нова версія, і побачити список змін;
- «Оновити до …» — поставити її;
- «Архів вручну» — завантажити `graj-club-….zip` з комп'ютера (наприклад, якщо хостинг не має доступу до GitHub);
- «Відкотити» — повернути код, який був до останнього оновлення.

Що відбувається при оновленні:
1. Резервна копія поточного коду (дві останні зберігаються в `storage/app/private/updates`).
2. Заміна файлів. `.env`, `storage/` і `public/storage` не чіпаються, `install.php` не повертається.
3. Міграції бази й кеш (`migrate --force`, `optimize`).

Якщо cron працює, кнопки ставлять оновлення в чергу, і він виконує його протягом хвилини — без обмеження часу запиту. Якщо cron не працює, оновлення виконується прямо в браузері.

Відкат повертає лише код: зміни бази (міграції) не відкочуються.

**Через SSH:** `php artisan site:update` (оновити), `--check` (перевірити), `--rollback` (відкотити).

**Приватний репозиторій:** додайте в `.env` `UPDATE_TOKEN` — fine-grained токен GitHub із правом Contents: read. Інший репозиторій — `UPDATE_REPO=власник/назва`.

**Без адмінки й SSH:** розпакуйте новий архів поверх старого, не чіпаючи `.env` і `storage/`, потім разовою cron-задачею виконайте `cd /шлях/до/graj && php artisan migrate --force && php artisan optimize`.
